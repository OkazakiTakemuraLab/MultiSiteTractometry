# MultiSiteTractometry
Code and data for reproducing figures in:

Taguma, D., et al. A traveling-head study on the reliability of diffusion MRI-based tractometry across scanners and acquisition protocols. Manuscript under review.

The code was tested using MATLAB R2021b Update 6 on Ubuntu 20.04.6 LTS.

External MATLAB tools
This repository includes or uses code derived from the following external resources:
1. Fortin, J.-P., et al. (2017). Harmonization of multi-site diffusion tensor imaging data. NeuroImage, 161, 149–170.
2. Bechtold, B. (2016). Violin Plots for Matlab.
3. Salarian, A. (2008). Intraclass Correlation Coefficient (ICC). MATLAB File.
